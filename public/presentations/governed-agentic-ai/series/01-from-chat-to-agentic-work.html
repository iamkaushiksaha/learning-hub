OpenAI orchestration and handoffs
Complexity gate

More agents do not automatically create more value.

Stay single-agent when
  • One prompt and a few tools solve the task
  • All steps use the same context
  • There is one definition of done
  • Specialists would only repeat each other
Consider multi-agent when
  • Expert roles have different evidence and instructions
  • Work can proceed independently
  • Hand-offs are typed artifacts
  • An independent reviewer adds real assurance
+Specialization
