## Retention design

Every generated learning page uses the same cognitive rhythm:

1. A short mental model establishes the vocabulary.
2. A responsive visual externalizes the system or decision.
3. A comparison table separates commonly confused concepts.
4. A cybersecurity scenario transfers the idea into practice.
5. Three recall statements and a teach-back prompt reinforce memory.
6. FAQ answers address predictable objections and misconceptions.
7. Primary sources let advanced readers verify and continue learning.

Analytics are intentionally not included yet. If privacy-respecting analytics
are added later, measure path progression, source-link engagement, FAQ use,
presentation-to-article transitions, and return visits—not invasive prompt or
content capture.
